# [BUG-015] [Login] Bottom Navigation Tab Bar is Visible and Interactive Before Authentication

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: `tab-products`, `tab-cart`

## Steps to Reproduce
1. Launch app with fresh state on the Login screen (unauthenticated state).
2. Inspect the bottom of the screen.

## Expected Result
Bottom navigation tab bar (`tab-products`, `tab-cart`) must remain hidden until the user successfully authenticates.

## Actual Result
Bottom navigation tab bar is rendered and interactable immediately upon app launch, allowing users to tap into Products and Cart tabs while still on the Login screen.

## Severity & Impact
- **Severity**: Major
- **Rationale**: Breaks navigation state gating by exposing authenticated views before credentials are provided.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`App.js`).
- **Blocks**: None.
