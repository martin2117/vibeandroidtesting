# [BUG-010] [Checkout] CVV Field Opens QWERTY Text Keyboard and Accepts Non-Numeric Characters

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Espresso (`CheckoutTest.kt`) & Appium (`test_checkout.py`)
- **Target Element**: `checkout-cvv`

## Steps to Reproduce
1. Launch app with clean state and log in (`demo@techshop.com` / `password123`).
2. Add Product 1 (`add-p1`), switch to Cart (`tab-cart`), and navigate to Checkout (`proceed-checkout`). *(Note: On broken build, reaching Checkout requires patching blocker `BUG-011` / setting `Screen.Checkout`)*.
3. Tap on the CVV input field (`checkout-cvv`) to focus it and trigger the soft keyboard.
4. Observe the keyboard layout and attempt to enter alphabetic characters (e.g. `abc`).

## Expected Result
The CVV field must enforce a numeric soft keyboard (`KeyboardOptions(keyboardType = KeyboardType.Number)` in Compose / `keyboardType="numeric"` in React Native) and restrict input to exactly 3 or 4 numeric digits.

## Actual Result
The CVV field opens a standard QWERTY alphabetic keyboard (`KeyboardType.Text`), allowing arbitrary non-numeric text input without validation.

## Severity & Impact
- **Severity**: Major
- **Rationale**: Degrades input UX on mobile and allows invalid alphabetic security codes to bypass client-side validation.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`CheckoutScreen.js`).
- **Blocks**: Gated behind `BUG-011` on the broken build.
