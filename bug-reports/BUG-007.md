# [BUG-007] [Catalog] Long Product Title Exceeds Single Line and Overflows Cell Bounds

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Espresso (`GeneralTest.kt`) & Appium (`test_general.py`)
- **Target Element**: `name-p3`

## Steps to Reproduce
1. Launch app and log in (`demo@techshop.com` / `password123`).
2. Navigate to Catalog screen (`tab-products`).
3. Scroll down to Product 3 ("Ultra-Fast Wireless Charging Pad with Dual USB-C Outputs").
4. Inspect the title typography and bounding cell layout.

## Expected Result
Long product titles must be constrained to `maxLines = 1` with `TextOverflow.Ellipsis` (`numberOfLines={1}` in React Native) so the text is cleanly truncated without exceeding row boundaries.

## Actual Result
The title wraps across 3 full lines, causing the cell height to balloon (height: 189px vs <= 120px expected), overflowing and breaking the visual grid layout.

## Severity & Impact
- **Severity**: Minor
- **Rationale**: UI layout distortion that breaks visual consistency across diverse device screen sizes.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`CatalogScreen.js`).
- **Blocks**: None.

- Appium element height assertion (`assert 189 <= 120`) in [`appium/appium-report.xml`](file:///Users/mac/vibeandroidtesting/appium/appium-report.xml)
