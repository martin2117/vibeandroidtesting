# [BUG-011] [Checkout] "Proceed to Checkout" Button is Unresponsive (No-Op Empty Lambda)

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: `proceed-checkout`

## Steps to Reproduce
1. Launch app, authenticate (`demo@techshop.com` / `password123`).
2. Add Product 1 ($60.00) to the cart (`add-p1`).
3. Switch to Cart tab (`tab-cart`) (Subtotal >= $10.00).
4. Tap the "Proceed to Checkout" button (`proceed-checkout`).

## Expected Result
The app must transition from the Cart screen to the Checkout screen, displaying customer and payment input fields (`checkout-firstName`, etc.).

## Actual Result
Tapping the button produces no action or navigation. The `onClick` handler is wired to an empty lambda `{}` (`onProceed` callback not invoked in Compose, empty handler in React Native).

## Severity & Impact
- **Severity**: Blocker
- **Rationale**: Completely breaks the purchase funnel. Users cannot checkout or complete orders under any circumstances.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt` AppRoot) and React Native (`CartScreen.js`).
- **Blocks**: Blocks all checkout test cases (`TC-CHK-001` through `TC-CHK-009`) across all 4 automation suites.
