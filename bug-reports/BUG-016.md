# [BUG-016] [Login] Primary Login Submit Button Missing Test Identifier (testTag / resource-id)

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: None *(Missing ID / Testability Defect)*

## Steps to Reproduce
1. Launch app on the Login screen.
2. Inspect the view hierarchy and accessibility properties of the "Log In" button.

## Expected Result
Primary "Log In" button must declare a dedicated, stable test identifier (`Modifier.testTag("login-submit")` in Compose / `testID="login-submit"` in React Native) mapping to `resource-id="login-submit"`.

## Actual Result
The button possesses no `testTag` or `resource-id` (reports `null`). Test automation must fall back to fragile visible text locators (`"Log In"`).

## Severity & Impact
- **Severity**: Major
- **Rationale**: Testability defect that destabilizes cross-framework automated test suites and prevents reliable localized test targeting.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`LoginScreen.js`).
- **Blocks**: Impairs black-box test locators across all suites.
