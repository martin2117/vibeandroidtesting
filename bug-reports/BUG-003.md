# [BUG-003] [Login] Authentication Bypass When Submitting Invalid Password

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: `login-password`, `login-error`

## Steps to Reproduce
1. Launch app with fresh state on the Login screen.
2. Enter `demo@techshop.com` into the Email input (`login-email`).
3. Enter `wrongpassword123` into the Password input (`login-password`).
4. Tap the "Log In" button.

## Expected Result
Authentication must fail. The app must stay on the Login screen and display an error message (`login-error`) stating "Invalid email or password".

## Actual Result
Invalid credentials are accepted without checking against valid user store. The app navigates straight to the Product Catalog screen.

## Severity & Impact
- **Severity**: Critical
- **Rationale**: Broken authentication logic allows arbitrary passwords to authenticate and access user accounts.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`AppViewModel.kt`) and React Native (`AuthContext.js`).
- **Blocks**: None.
