# [BUG-008] [Catalog] Out of Stock Badge Incorrectly Styled in Green Color

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Espresso (`GeneralTest.kt`) & Appium (`test_general.py`)
- **Target Element**: `stock-p4`

## Steps to Reproduce
1. Launch app and log in (`demo@techshop.com` / `password123`).
2. Navigate to Catalog screen (`tab-products`).
3. Scroll down to Product 4 (`stock-p4`).
4. Inspect the badge text and its rendered color styling.

## Expected Result
The "Out of Stock" status badge must be rendered in Red (`Color.Red` / `#e74c3c`) to indicate an unavailable item state.

## Actual Result
The badge text is rendered in Green (`Color.Green` in Compose / `#2ecc71` in React Native), misleading users into perceiving the item as in stock.

## Severity & Impact
- **Severity**: Minor
- **Rationale**: Confusing semantic color cue that contradicts the text status and user affordance.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`CatalogScreen.js`).
- **Blocks**: None.
