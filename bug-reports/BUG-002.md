# [BUG-002] [Login] Authentication Bypass When Submitting Empty Credentials Form

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: `login-email`, `login-password`, `login-error`

## Steps to Reproduce
1. Launch app with fresh state on the Login screen.
2. Leave both Email (`login-email`) and Password (`login-password`) inputs blank.
3. Tap the "Log In" button.

## Expected Result
Form submission must be rejected. The app must remain on the Login screen and display an inline error message (`login-error`) stating "Please enter both email and password".

## Actual Result
Submission is accepted without validation. The app authenticates the empty session and navigates directly to the Product Catalog screen (`catalog-title`), bypassing authentication.

## Severity & Impact
- **Severity**: Critical
- **Rationale**: Complete authentication bypass allowing unauthenticated access to the catalog and cart with blank credentials.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`AppViewModel.kt`) and React Native (`AuthContext.js`).
- **Blocks**: None.
