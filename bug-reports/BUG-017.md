# [BUG-017] [Checkout] Soft Keyboard Covers Focused CVV Field Without IME Inset Padding

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Espresso (`CheckoutTest.kt`) & Appium (`test_checkout.py`)
- **Target Element**: `checkout-cvv`

## Steps to Reproduce
1. Launch app with clean state and log in (`demo@techshop.com` / `password123`).
2. Add Product 1 (`add-p1`), switch to Cart (`tab-cart`), and navigate to Checkout (`proceed-checkout`). *(Note: On broken build, reaching Checkout requires patching blocker `BUG-011` / setting `Screen.Checkout`)*.
3. Scroll to the bottom of the Checkout form.
4. Tap the CVV input field (`checkout-cvv`) to focus it and open the software keyboard.
5. Attempt to view the CVV input or scroll the form further down while keyboard is open.

## Expected Result
The form container must apply IME window insets (`Modifier.imePadding()` in Compose / `KeyboardAvoidingView` in React Native) and maintain scrollability so the focused field is pushed into view above the keyboard.

## Actual Result
The layout is a plain `Column`/`View` without IME insets. The soft keyboard permanently obscures the CVV field, and the view cannot be scrolled into view while the keyboard is displayed.

## Severity & Impact
- **Severity**: Major
- **Rationale**: Blocks user input on standard mobile screen sizes during credit card CVV security code entry.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`CheckoutScreen.js`).
- **Blocks**: Gated behind `BUG-011` on the broken build.
