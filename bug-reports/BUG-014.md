# [BUG-014] [Catalog] Top Navigation Bar Title Displays "Untitled" Instead of "Products"

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator
- **Target Element**: `catalog-title`

## Steps to Reproduce
1. Launch app and log in (`demo@techshop.com` / `password123`).
2. Observe the top navigation header on the Product Catalog screen (`catalog-title`).

## Expected Result
Top navigation bar header must display the title "Products".

## Actual Result
Top navigation bar header displays "Untitled", indicating a placeholder string left in production layout.

## Severity & Impact
- **Severity**: Minor
- **Rationale**: Cosmetic and brand defect displaying placeholder text in primary navigation.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`App.js`).
- **Blocks**: None.
