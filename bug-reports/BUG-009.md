# [BUG-009] [Checkout] Payment Form Accepts Expired Credit Card Date Without Validation

## Environment
- **Build**: Jetpack Compose & React Native (Broken build)
- **Device/OS**: Android 14 (API 34) on Pixel 7 Emulator
- **Detected By**: Maestro, Appium, Espresso, UI Automator (Verified on fixed proceed hook)
- **Target Element**: `checkout-expiry`, `checkout-submit`, `checkout-error`

## Steps to Reproduce
1. Launch app with clean state and log in (`demo@techshop.com` / `password123`).
2. Tap "Add" on Product 1 (`add-p1`) and switch to Cart tab (`tab-cart`).
3. Navigate to Checkout screen (`proceed-checkout`). *(Note: On the broken build, reaching Checkout requires patching blocker `BUG-011` / setting `Screen.Checkout`)*.
4. Fill customer details:
   - First Name (`checkout-firstName`): `Jane`
   - Last Name (`checkout-lastName`): `Doe`
   - Email (`checkout-email`): `jane.doe@example.com`
   - Phone (`checkout-phone`): `5551234567`
5. Fill payment details with an expired date:
   - Card Number (`checkout-card`): `4111222233334444`
   - Expiry (`checkout-expiry`): `01/20` (MM/YY in the past)
   - CVV (`checkout-cvv`): `123`
6. Tap "Place Order" button (`checkout-submit`).

## Expected Result
Checkout form validation must reject expiration dates prior to the current month/year, display an error message in `checkout-error` ("Card is expired"), and block order placement.

## Actual Result
The form accepts past expiration dates without any validation and completes order placement, navigating to the confirmation screen.

## Severity & Impact
- **Severity**: Major
- **Rationale**: Invalid payment submissions will cause merchant gateway payment failures and chargeback errors.

## Scope & Blockers
- **Cross-Build Behavior**: Reproduces on both Jetpack Compose (`MainActivity.kt`) and React Native (`CheckoutScreen.js`).
- **Blocks**: Gated behind `BUG-011` on the broken build.

## Evidence
- Blocked by `BUG-011` assertion failures across [`appium/appium-report.xml`](file:///Users/mac/vibeandroidtesting/appium/appium-report.xml) and [Gradle Test Report](file:///Users/mac/vibeandroidtesting/techshop/compose-broken/app/build/reports/androidTests/connected/debug/index.html)
